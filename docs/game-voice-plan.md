## 原神可核對角色配置

124筆名冊角色皆已收錄，依固定版本角色資料的gender欄位核對：82位女性用女聲、42位男性用男聲，八種聲線皆使用。同一角色所有短句保持同一聲線；奇偶使用來源可核對的指定聲型。逐角色配置、來源及情境限制見[原神完整配音表](genshin-completion.md)。獨立性別fixture與全來源角色覆蓋測試防止新增批次漏收或再度錯配。
