**新核實位置**：`general-listening-166.grammar[0].note`，[day191.mjs:138](../curriculum/days/day191.mjs#L138)：「複習普通形加ので。」；同課`grammar[1].note`，[day191.mjs:163](../curriculum/days/day191.mjs#L163)：「複習普通形加とき表示時間背景。」兩處按同一摘要省略原因合併。

本課四例及對話均使用動詞，接續正確；重點是因果與同時背景的區別。若讀者直接從單課摘要類推名詞／な形容詞，會缺少非過去肯定的特別形態：ので前用な，とき前名詞用の、な形容詞用な。這是跨詞類類推風險，**不是現有例句發生錯接**。通用72課`grammar[1]`已明說名詞／な形容詞なので，94課亦有；とき的通用112課明限動詞時序，N5第23天另有四詞類接續。這些先備及「複習」定位支持保留為改善，不沿用初次介紹51課的確認缺陷嚴重度。

**查證**：東京外大[S1「理由」](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/081.html)「文の作り方」第1點區分普通形／丁寧形及N／NA非過去肯定なので；[S2「～とき」](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/093.html)第1、3點分列動詞／い形容詞、NAな、Nの，第7點另談過去形。不能概括成所有名詞／な形容詞時態都替換成な／の。

### B2-I2｜低：第158課可用情境條件表述，減少必要／充分術語的額外負擔

**位置與原文**：`general-listening-158.grammar[0].note`，[day183.mjs:138](../curriculum/days/day183.mjs#L138)：「證件齊全是通常的必要條件，遇到停用例外仍不得通行；不要把通常規則當任何時候的充分條件。」既有例句[day183.mjs:144](../curriculum/days/day183.mjs#L144)「許可証があれば、通常は橋を渡れる。」與對話第2輪的通常／今日補修對比，已能支持本課所有題目。

**判定與影響**：許可證在設定中作通行要求可以成立，沒有證據證明此處規定錯誤。但單憑「あれば通常は渡れる」不能額外推出「沒有許可證絕對不准」；本課也不考查無證的其他情況。數理術語把注意力引到未明說的逆向規則，對本來要聽清「通常／今天全員禁止」的讀者未必有幫助。這是教材說明負擔與範圍改善，**不判定ば必然只表充分條件，也不判定許可證不是必要條件**。

**查證**：外大[S4「条件」](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/083.html)第1、4～5點說明條件與一般／一次假設；第16點亦承認在特定脈絡可焦點化為達成後項所需前項。不能單以形式邏輯排除語境中的必要性解讀；本建議依本課文字界線提出，而非將該來源當成此虛構通行規定的證明。

**最小建議／驗證**：可將前段改為「有證通常可通行，但今天補修，全員都不能過」的意思，保留現有例句／題目；避免順手加入無證通行規則。確認解說仍能推出三題各唯一答案、沒有暗示恢復時刻已公布。若只有note變更，無需重製音檔或重設題目ID。
