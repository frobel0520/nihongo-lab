## 重現與根因

代表卡：`game-card:game:er:sissela:selection-voice:992579e355:992579e355`，遊戲類；原文「落ち着いてください、ウィルソン。今日はどんなお客さんが来てくれるのか、楽しみです。」。同一份教材、相同字級與視窗對照兩個正式`/nihongo-lab/` build。

- 手機`.screen.srs-page`固定為`100dvh - --stack-top`。教材類別、複習／新卡、進度、上一／下一張、評分及底部分頁列先占空間，剩下才給`.flashcard-area`的獨立捲動區。根字級變大會增加上述列高，卡內可讀高度降到61px，矮螢幕可降到0。
- 揭示前後都受同一個容器限制；長句在揭示前已超出卡內視窗。揭示後的三欄grid還為播放鈕左右各留44px，使句子文字欄更窄、內容更高。這不是圖片造成；圖片仍在翻譯後、56×42。
- 641px以上切到桌面導覽，長句雖是頁面捲動，評分列卻仍sticky，橫向時會浮在文字上方。568×320＋130%時揭示按鈕還被底部分頁列攔住（基準pointer無法點；只能以鍵盤揭示後繼續量測）。

## 修正與取捨

1. SRS頁用**最小高度**而非固定高度，長卡隨整頁自然延伸；移除卡內垂直捲動。只保留一個閱讀捲動軸，其他頁面不變。
2. SRS評分／揭示在卡片後的正常文件流，不再吸底蓋住文字。短卡仍靠頁面最小高度將操作維持在下方；長卡需要讀完後捲到操作區。這是明確取捨，不保證所有長卡的播放、全文與評分同時出現在一屏。
3. 超過16個Unicode字元的詞面採長句排列：揭示後文字跨滿卡片寬度，播放鈕在獨立的上一列。16是純排列啟用條件，不是教材或詞義分類；短單字排列不變。所有日文、讀音與翻譯字級不變，中心線仍置中，圖片仍在翻譯下方、空alt。
4. 換到不同卡片時，若已捲頁，回到新卡開頭，避免停在前卡答案尾端；同卡揭示不任意搬頁。沿用T163鍵盤焦點目標，只在鍵盤操作後焦點掉到body時移到評分區／顯示答案；改為將該操作捲到可見處。滑鼠／觸控不搬焦點。水平滑動換卡、垂直閱讀不評分的既有判定保持。
