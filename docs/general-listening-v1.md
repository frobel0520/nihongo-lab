# 動漫／遊戲通用聽解：起始九課

目前提供九課可直接學習的原創教材，由課程首頁的「動漫／遊戲通用聽解」入口進入第1階段。每課25個單字、2個文法重點（各2句例句）、6句男女聲情境對話、3個句型練習及3題整段理解題；合計225個單字條目、18個文法重點、54句對話、27題理解與315個VOICEVOX音檔。不把原創對話標成遊戲或動漫原句。

適合已能讀基本假名、有N5概念的人；需要打底可先學現有的N5復健課。每天30～45分鐘，先聽整段，再學單字／文法／句型，答題後看解析並逐句跟讀，最後用單字卡複習。第4～6課逐步介紹N4的可能形與條件句，先學例句再回到對話確認意思。第7～9課辨認願望、義務、許可與禁止，並練なきゃ、ちゃだめ等口語縮略。原有聽寫與跟讀句庫也納入九課例句及對話。

播放完整六句後才開放理解題；中途停止或播放失敗不算完整聽過。三題皆作答後揭示答案、解析與原文。播放固定1倍速，不提供速度選項。每段同伴甲固定女聲雨晴はう、同伴乙固定Nemo男声2；單字讀音練習使用專案既有八種聲線。

理解題使用獨立scene識別碼，保存於既有版本3進度；原文或題義改動會重設識別碼，音色與解說修訂保留紀錄。首頁會顯示理解進度；重新練習不刪除曾答對的紀錄。答對表示曾完成本練習，不等同盲聽陌生作品或掌握真人演技。切換分頁或課程時停止播放器；提供本課35檔與全部九課315檔的離線下載。

## 擴充路線

六階段各30課，共180課為規劃目標，目前只有上述九課已完成。

1. 聲音與基本句子：人物、動作、否定與基本指示。
2. 日常互動：請求、邀請、原因與同伴聊天。
3. 作品常見口語：縮略、省略、命令與句尾語氣。
4. 劇情理解：條件、意圖、轉折與事件經過。
5. 情境詞彙：探索、戰鬥、魔法、推理與人際關係。
6. 綜合聽解：較長對話、指代、隱含意思與實際作品的速度、情緒。

後續增加辨音與跨情境練習，再逐步加入較長的陌生對話。真實作品素材與合成教學音聲分開標示；初版未收錄作品原配音，也不以合成語音答題率推定作品理解率。
