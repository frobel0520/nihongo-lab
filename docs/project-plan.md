# かなの日本語：專案計畫

更新：2026-10-07（初版 2026-09-29）。目標使用者：個人學習者。版本：0.1.0。

## 目標與範圍

長期目標是通過 JLPT N1；近期目標是不看字幕也能抓到動畫與遊戲日文配音的大意。網站提供聽寫練習、循環跟讀（不含調速）、SRS 單字卡、口語轉換表、詞彙主題包，教材由 Claude 或 GPT 直接撰寫完整內容，使用者只需讀 / 聽 / 練習，不需中途自行填入或貼台詞。

不包含：動畫台詞匯入（.srt/.ass 或手動貼上）與多使用者帳號。Google 登入及 Cloudflare 同步已作為選配功能完成，未登入時不影響本機學習。

2026-09-30 更新：動畫這一塊改用「內建名句包」（T13）處理，而不是讓使用者匯入字幕：由 Claude 或 GPT 寫好單句短台詞、出處與口語解說，音檔自製，所以聽寫、跟讀、SRS 都能直接沿用。字幕檔匯入維持不做。跟讀（T05）也調整範圍：只做循環跟讀，不做調速。

2026-09-29 更新：目標包含「做成應用程式」——參考另一個既有的 PWA 專案的模式：React PWA（可安裝、離線可用）+ Cloudflare Worker 做 SRS 進度跨裝置同步。不需要 Family 的 Google OAuth 多人登入與推播，因為 nihongo-lab 只有 使用者 一人用。細節見 project-sa.md、project-sd.md「PWA 與跨裝置同步」。

## 第 0 階段路線圖（N5 復健）

- 對照《大家的日本語》第一冊 25 課，每天推進約 1～2 課，落在原訂 2～3 週（約 15～20 天）。
- N5 沒有官方單字／漢字／文法清單（官方自 2010 年起不再公布）。本專案以 [OpenJLPT](https://github.com/evanclan/OpenJLPT)（CC BY-SA 4.0；級別出自 Jonathan Waller 的社群清單，不是官方標準）為對照基準：N5 共 674 個單字、84 個漢字、81 個文法點，用 `npm run coverage` 量測。坊間常見的「800～1000 詞彙、100～103 漢字、80～90 文法點」查無原始出處（本文件先前寫的「見下方 Sources」段落並不存在），不當驗收依據。《大家的日本語》的官方單字表不在手邊，所以「25 課完整涵蓋 N5」目前是待驗證的目標，不是已知事實。
- 《大家的日本語》本冊課文不含漢字教學（漢字是獨立的《漢字冊》），所以另外排一條**漢字進度**，跟課程平行推進，目標是這 2～3 週內看過 N5 漢字表的 84 字，加上教材日文實際用到的 N4 漢字（第 1 天已有 5 個：会員田社私）的讀音與意思，不要求會手寫。N5 表外的漢字不刻意避開：N5 的 674 個單字若都寫成漢字，會用到約 417 個不同漢字。
- 每天教材完成後，才能在 release-audit.md 記錄「N5 復健完成」；不是寫了幾天就算數。

## 教材密度與口語連動（2026-09-30 定案）

`npm run coverage` 的對照結果：第 1 天只涵蓋 N5 單字 6／674、漢字 9／84、文法 5／81。要在 25 課內涵蓋 N5，剩下 24 課平均每課要補約 28 個單字、3 個漢字、3 個文法點；照第 1 天的單字量（9 個）寫完 25 課，只會到 N5 單字的三分之一。第 2 天起：

- **單字**：每課以 25～30 個為目標（N5 的 674 字為底線；N4 單字另計）。每課寫完都跑 `npm run coverage`，把數字記進 release-audit.md；課文若需要教科書專用詞（如 会社員、何人），照寫，不必硬湊清單。
- **漢字**：教材日文用到的漢字都要能被 T02b 追蹤到，包含 N5 表外的（多半是 N4）。
- **文法**：每個文法點都標 `jlpt`（OpenJLPT 的文法 id），才算得出涵蓋率。
- **口語連動**：T07 的重點，在教到對應文法那一課順手帶出口語形，不必等第 2 階段。對照見下表；N4 的項目等 N4 教材再連動，目前先留在 T07。
- **已決定（T22，2026-09-30）**：SRS 不設每日新卡上限，沒看過的單字一次全部排進佇列（使用者要求；原本每天 10 張，一課 30 個單字要 3 天才進得完）。取捨：教材增加後單次佇列會很長；若之後覺得太多，做成畫面上可選的每次張數，而不是改回固定上限。

## Pageflow

開啟網站 → 選學習階段（第 0～3 階段）→ 選課程 → 閱讀教材（例句、單字、文法說明）→ 練習（聽寫 / 跟讀 / SRS）→ 對照答案並標錯處 → 記錄完成 → 下一課。

錯誤流程：找不到音檔或教材時顯示明確錯誤，不靜默失敗；離線時仍可讀取已快取教材；音檔需事先下載才能離線播放（T16），沒下載的音檔離線時顯示明確錯誤；儲存失敗需明確提示。

## 交付條件

- 第 0 階段（N5 復健）教材完整可讀，對應《大家的日本語》第一冊 25 課文法 + N5 漢字表 84 字與教材實際用到的 N4 漢字。
- 聽寫練習、循環跟讀（不做調速，2026-09-30 決定）、SRS 單字卡三項核心功能可用。
- PWA 可安裝、離線可用（manifest、icon、service worker）。
- SRS 進度跨裝置同步（Cloudflare Worker，參考既有 PWA 專案的資料儲存模式），離線時退回本機儲存、之後自動補同步。
- TypeScript 檢查、測試、lint、production build 通過（`npm run check`、`npm run build`）。
- 不依賴會產生費用的第三方服務；不將個人句庫或台詞放進公開 repo。
- 不把未執行的驗證寫成通過；瀏覽器真實操作 QA 未做時標記 pending。
