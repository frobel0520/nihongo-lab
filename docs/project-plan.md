# 日本語 Lab：專案計畫

日期：2026-09-29。目標使用者：Michael 本人。版本：0.1.0。

## 目標與範圍

長期目標是通過 JLPT N1；近期目標是不看字幕也能抓到動畫與遊戲日文配音的大意。網站提供聽寫練習、跟讀與慢速播放、SRS 單字卡、口語轉換表、詞彙主題包，教材由 Claude 直接撰寫完整內容，使用者只需讀 / 聽 / 練習，不需中途自行填入或貼台詞。

不包含：動畫台詞匯入（.srt/.ass 或手動貼上）、多使用者帳號、跨裝置同步、真實外部 API。這些列為之後才考慮的選配功能，不影響核心學習迴圈。

## SDLC 參考與調整

參考 [typescript-lab](https://github.com/frobel0520/typescript-lab) 與其引用的 software-engineering-workshop：專案級 Pageflow → SA → SD → 任務拆解 → 可重複驗收；完成條件通過才記錄進度。功能分支使用 feature/<task-id>。

## Pageflow

開啟網站 → 選學習階段（第 0～3 階段）→ 選課程 → 閱讀教材（例句、單字、文法說明）→ 練習（聽寫 / 跟讀 / SRS）→ 對照答案並標錯處 → 記錄完成 → 下一課。

錯誤流程：找不到音檔或教材時顯示明確錯誤，不靜默失敗；離線時仍可讀取已快取教材與繼續練習，儲存失敗需明確提示。

## 交付條件

- 第 0 階段（N5 復健）教材完整可讀，涵蓋五十音複習與《大家的日本語》第一冊核心文法。
- 聽寫練習、跟讀慢速播放、SRS 單字卡三項核心功能可用且進度存在瀏覽器。
- TypeScript 檢查、測試、lint、production build 通過（`npm run check`、`npm run build`）。
- local-first：離線可用，不依賴 CDN；不將個人句庫或台詞放進公開 repo。
- 不把未執行的驗證寫成通過；瀏覽器真實操作 QA 未做時標記 pending。
