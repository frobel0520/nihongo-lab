# 日本語 Lab：專案計畫

日期：2026-09-29。目標使用者：Michael 本人。版本：0.1.0。

## 目標與範圍

長期目標是通過 JLPT N1；近期目標是不看字幕也能抓到動畫與遊戲日文配音的大意。網站提供聽寫練習、跟讀與慢速播放、SRS 單字卡、口語轉換表、詞彙主題包，教材由 Claude 直接撰寫完整內容，使用者只需讀 / 聽 / 練習，不需中途自行填入或貼台詞。

不包含：動畫台詞匯入（.srt/.ass 或手動貼上）、多使用者帳號、真實外部 API。這些列為之後才考慮的選配功能，不影響核心學習迴圈。

2026-09-30 更新：動畫這一塊改用「內建名句包」（T13）處理，而不是讓使用者匯入字幕：由 Claude 寫好單句短台詞、出處與口語解說，音檔自製，所以聽寫、跟讀、SRS 都能直接沿用。字幕檔匯入維持不做。跟讀（T05）也調整範圍：只做循環跟讀，不做調速。

2026-09-29 更新：目標包含「做成應用程式」——參考 [Family](https://github.com/frobel0520/Family) 的模式：React PWA（可安裝、離線可用）+ Cloudflare Worker 做 SRS 進度跨裝置同步。不需要 Family 的 Google OAuth 多人登入與推播，因為 nihongo-lab 只有 Michael 一人用。細節見 project-sa.md、project-sd.md「PWA 與跨裝置同步」。

## 第 0 階段路線圖（N5 復健）

- 對照《大家的日本語》第一冊 25 課，每天推進約 1～2 課，落在原訂 2～3 週（約 15～20 天）。
- N5 沒有官方單字／漢字／文法清單；業界共識約 800～1000 詞彙、100～103 漢字、80～90 個文法點（來源見下方 Sources）。25 課的內容普遍被認為完整涵蓋這個範圍。
- 《大家的日本語》本冊課文不含漢字教學（漢字是獨立的《漢字冊》），所以另外排一條**漢字進度**，跟課程平行推進，目標是這 2～3 週內看過全部 N5 常用漢字（約 100～103 字）的讀音與意思，不要求會手寫。
- 每天教材完成後，才能在 release-audit.md 記錄「N5 復健完成」；不是寫了幾天就算數。

進度追蹤：已完成第 1 天（對應大家的日本語 L1：は／です／も／ですか／ではありません），見 [task-breakdown.md](task-breakdown.md)。

## SDLC 參考與調整

參考 [typescript-lab](https://github.com/frobel0520/typescript-lab) 與其引用的 software-engineering-workshop：專案級 Pageflow → SA → SD → 任務拆解 → 可重複驗收；完成條件通過才記錄進度。功能分支使用 feature/<task-id>。

## Pageflow

開啟網站 → 選學習階段（第 0～3 階段）→ 選課程 → 閱讀教材（例句、單字、文法說明）→ 練習（聽寫 / 跟讀 / SRS）→ 對照答案並標錯處 → 記錄完成 → 下一課。

錯誤流程：找不到音檔或教材時顯示明確錯誤，不靜默失敗；離線時仍可讀取已快取教材與繼續練習，儲存失敗需明確提示。

## 交付條件

- 第 0 階段（N5 復健）教材完整可讀，對應《大家的日本語》第一冊 25 課文法 + N5 常用漢字（約 100～103 字）。
- 聽寫練習、跟讀慢速播放、SRS 單字卡三項核心功能可用。
- PWA 可安裝、離線可用（manifest、icon、service worker）。
- SRS 進度跨裝置同步（Cloudflare Worker，參考 Family 的資料儲存模式），離線時退回本機儲存、之後自動補同步。
- TypeScript 檢查、測試、lint、production build 通過（`npm run check`、`npm run build`）。
- 不依賴會產生費用的第三方服務；不將個人句庫或台詞放進公開 repo。
- 不把未執行的驗證寫成通過；瀏覽器真實操作 QA 未做時標記 pending。
