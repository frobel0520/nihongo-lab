- [GOV.UK：任務式主持易用性測試](https://www.gov.uk/service-manual/user-research/using-moderated-usability-testing)：閱讀任務設計、執行、合成資料及輔助技術章節。借用「具體目標、合理順序、可重現紀錄」設計走查；本輪沒有參與者，因此不能稱為主持式使用者測試。

來源均回傳 HTTP 200。外部全文僅暫存作閱讀，沒有複製進 repo。本文沒有任意 UX 總分，也沒有宣稱全站 WCAG 合規。U1 與文字縮放／重排準則相關，但根字級模擬不能直接當成原生 zoom、OS 字型或完整合規測試。

### 視窗、鍵盤與錯誤情境

- **375×667 主畫面**：上述旅程皆有實際操作。四類 SRS 揭示前無圖、揭示後圖在翻譯下方、固定1倍播放。四類跟讀實際啟動、停止、揭示及下一句；跟讀沒有被描述成發音評分系統。
- **聽寫幾何矩陣**：375×667／100%、320×568／100%、320×480／150%、667×375／100%、375×667／200%根字級。全部未見水平溢位，但其中一案作答區高度0，另一案只剩71px；不能以「沒有橫向溢位」宣稱閱讀通過。
- **其他頁補查**：設定、通用121文法、柯萊角色頁各測320×480／150%與667×375／100%，6案未見水平溢位。SRS大字、矮螢幕與同ID／鍵盤定位另沿用已複核且現版產品相同的T164證據；沒有宣稱所有頁面／卡片都跑完全部矩陣。
- **鍵盤／點擊目標**：Enter揭示後焦點在評分fieldset；下一次Tab到「還不會」，可見實線焦點且中心點可命中。設定頁主要按鈕高度44px、顯示切換52×32px。Kanjium內文連結高19px屬內文例外，不因此判定違反2.5.8；沒有以44px當作AA通用硬門檻。
- **對比抽測**：首頁14.08px次要文字 `rgb(90,103,98)`／白色約5.91:1，標題文字 `rgb(23,32,29)`／白色約16.66:1。只代表這兩組實測樣本，不是全站對比認證。
- **排除誤報**：聽寫正／誤除顏色外還有勾／叉；回饋使用原生`output`，不能只因找不到顯式`role=status`就判為4.1.3違反。未做實體螢幕閱讀器驗收。
- **慢圖／失敗**：600ms慢圖前後評分區位置保持；單張圖失敗仍可顯示文字、評分及切卡。教材chunk單次失敗會顯示可理解的錯誤與重新載入按鈕，解除故障後確實回到可操作聽解頁。
- **真正離線**：`setOffline(true)`、重新載入，未快取探針出現`ERR_INTERNET_DISCONNECTED`；四類8次卡片／聽寫播放抽驗保持1倍。僅先準備代表音圖，不將命中快取當成有網路。

### U1／P2：聽寫在矮螢幕＋大字時，作答區縮成0高度

- **旅程／頁面／情境**：聽寫選擇題；`#/dictation?category=n5`；320×480、根字級150%（實際24px）。本輪已核實N5第1句，不推定所有題目都相同。
- **重現**：新設定檔選N5聽寫、保持選擇題；在上述尺寸／字級閱讀四個選項。375×667／100%作對照。
- **實際／預期／影響**：`.dictation-workspace`的clientHeight由對照242px變成0，內容scrollHeight仍400px；播放列自291.8px開始，覆蓋在作答區預期位置。選項不能由正常可見閱讀操作取得；沒有水平溢位並不能補救。預期所有選項／輸入與回饋仍有可讀、可到達的區域，不必縮字或停用放大。
- **證據**：[正常尺寸](previews/project-ux-dictation-normal.png)／[0高度畫面](previews/project-ux-dictation-small-large-text.png)，以及JSON內dictationGeometry。320×568／100%尚有117px，375×667／200%有71px；這些不能合併當作全部失敗。
- **實作位置**：[`app/globals.css:1163`](https://github.com/frobel0520/nihongo-lab/blob/38a660cb945d7ab2ddc910df6c4abc5cbf48d740/app/globals.css#L1163)固定整頁高度並扣除底部操作列；[`app/globals.css:1189`](https://github.com/frobel0520/nihongo-lab/blob/38a660cb945d7ab2ddc910df6c4abc5cbf48d740/app/globals.css#L1189)讓剩餘空間成為內層捲動區。這是**聽寫**的另一個版面條件，不是重開已結案的SRS F10。
