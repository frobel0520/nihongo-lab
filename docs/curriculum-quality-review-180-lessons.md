## 優先處理的確認問題

### C1｜中：第51課初次介紹「らしい」時，接續規則沒有排除名詞／な形容詞的非過去肯定「だ」

- **資料位置**：`general-listening-51.grammar[1].note`（索引從0起），[curriculum/days/day76.mjs:61](../curriculum/days/day76.mjs#L61)；同點例句 [day76.mjs:73](../curriculum/days/day76.mjs#L73)。這是通用系列首次以文法重點介紹 `rashii`，不能假設前一課已交代其接續例外。
- **原文**：「普通形接らしい，常依間接資訊判斷。不能把推斷當成已親自確認。」例句卻正確使用「新しい情報らしい。」；同課前一點另有「店は今日休みだそうです。」。
- **確認的錯誤範圍**：接續規則的適用範圍不正確，**不是兩句日文本身有錯**。動詞、い形容詞可接普通形；名詞／な形容詞的非過去肯定不能把「だ」直接留下。照目前沒有詞類限制的規則，以「新しい情報だ」「元気だ」代入，會產生不適用的「新しい情報だらしい」「元気だらしい」。這兩句是審查反例，並非現有教材原句。
- **原因與影響**：同課正在對照傳聞そうだ與らしい，兩者恰好在此接續不同；只說都接普通形，學習者難以從解說推出例句為何少了だ，容易把正確的「休みだそうだ」類推到らしい。
- **查核證據**：[東京外国語大学言語モジュール](https://www.coelang.tufs.ac.jp/mt/ja/gmod/contents/explanation/076.html)的「そうです②」「らしいです」造句說明分別列出名詞／ナ形容詞接だ與直接接續的差異。只據此判定接續範圍；沒有把「らしい必定只是傳聞」當成規則。
- **建議方向／驗證**：限定「動詞／い形容詞普通形」，另列名詞／な形容詞非過去肯定去だ；補一組そうだ／らしい最小對照，並保留過去及否定形可接的區別，避免錯教成所有だ都刪除。人工核對動詞、い形容詞、な形容詞、名詞四類及肯定／否定／過去，最後對照本課既有例句與翻譯。若只改解說，不應無故改動對話／練習 ID 或重製音檔。

同根因的**教學改善範圍**併在此，不另灌成多筆確認錯誤：第121課 `grammar[0].note` [day146.mjs:138](../curriculum/days/day146.mjs#L138)寫「普通形接ようだ，名詞接のようだ」，第127課 `grammar[1].note` [day152.mjs:163](../curriculum/days/day152.mjs#L163)寫「普通形加はずだ，名詞用のはずだ」，都省掉な形容詞的な。兩者是複習，前74／79／118課已提供較完整接續，且當課例句沒有用錯，故不把省略直接擴算成更多錯誤句。仍建議統一摘要，避免單課直接閱讀時規則變窄或失真。[國際交流基金「よう（１）」](https://www.jpf.go.jp/j/project/japanese/teach/tsushin/grammar/201307.html)列出ようだ前的な形容詞與名詞形態；はず的な／の接續亦見上述東外大頁面。其餘只教動詞用例的摘要，應寫明「動詞普通形」，不要機械地全部套上同一接續表。

## 教學改善建議（不計為確認錯誤）

### I1｜優先：第175課需要分開「還沒得知」與「客觀上尚未決定」

- **位置與資料ID**：`general-listening-175.dialogue[4]` [day200.mjs:226](../curriculum/days/day200.mjs#L226)、`dialogue[5]` [day200.mjs:234](../curriculum/days/day200.mjs#L234)、`practice[2]` [day200.mjs:253](../curriculum/days/day200.mjs#L253)、理解題 `understanding-3` [day200.mjs:285](../curriculum/days/day200.mjs#L285)。
- **原文鏈條**：「届く時刻はまだ聞いていないから、それも確かめる。」→「到着時刻までは決まっていないということだね。」→練習「負責人已定，時間還沒定」／「担当は決まったが、時刻はまだ決まっていない。」
- **原因／影響**：「甲還沒聽到」能與「接待員已定好但尚未告知」同時成立；因此不能單由第五句推導第六句的未決狀態。該課目標又是辨認引用範圍與「尚未確認的時刻」，這個推論容易教成未知＝未定。
- **分類理由**：第六句也可能被作者當作另補一個事實，且理解題確可由該句找到答案，所以本輪**不判定時刻實際已定、不列答案錯置**。問題在「ということだね」把新增前提包成重述，缺少讓讀者知道其來源的線索。
- **方向／驗證**：若目標是未知，保留「還不知道／還沒確認」，相應調整練習；若確實要教未定，先明說接待員尚未決定，再做重述。以「已定但甲未聽到」及「確實未定」兩個反例檢查答案能否區分，保留人稱方向。第90課已有追問後肯定回覆，第179課則另明說會合時刻未定，沒有把這兩課一起列成同樣錯誤。

### I2｜優先：全180課的三題答案均為三個位置各一次，形成可利用的題組線索

- **資料範圍**：全部 `general-listening-01`～`180.scene.questions[*].answer`。例如第1課 `destination/location/item` 的答案依序0、1、2，起於 [day26.mjs:146](../curriculum/days/day26.mjs#L146)；第51課 `understanding-1/2/3` 也是0、1、2，起於 [day76.mjs:146](../curriculum/days/day76.mjs#L146)。0表示第一個選項。
- **實際盤點**：180／180題組的排序都是 `[0,1,2]` 的排列；分布為012：64課、120：61課、201：50課、102：3課、021：2課、210：0課。540題個別答案三個位置各180題，看總體比例會漏掉題組內規律。
- **影響與證據邊界**：知道前兩題正確位置後，第三題的位置必定是未用過的那一個，無須理解第三題。這是實際題庫配置造成的額外線索，不是僅憑文字相似度評分。畫面依原陣列順序顯示選項（只為確認題目呈現，唯讀查看 [SceneListening.tsx:175](../app/components/SceneListening.tsx#L175)），並非資料中規律會被打散。這不表示所有人已利用它，也不否定既有完成紀錄；課程原本就沒有宣稱能力認證。
- **方向／驗證**：在既有題目範圍調整正確選項位置，容許同一題組重複答案位置，不必為此改產品或增加題數。盤點各位置總體及題組條件分布，人工重核正確答案與解析，避免只換位置卻忘了answer。語義仍比數字分布重要。涉及選項／答案的變更須依既有進度修訂規則處理。
- **干擾項附帶觀察**：第179課 `understanding-3.options[2]` [day204.mjs:289](../curriculum/days/day204.mjs#L289)的「明年的課程安排」與當前通訊情境無關。作基礎練習可成立，不列錯誤；後段可改以對話中確有出現、但屬另一人／另一時點／另一確定度的訊息設計干擾，避免只憑題材排除。不要全換成難以區分的近義句，仍須保證唯一可支持的答案。

### I3｜後續：第六階段仍以顯性重述為主，遷移到隱含意思／自然互動的證據有限

- **樣本與位置**：深審第151／156／165／169／172／175／179／180課；例如第156課 `dialogue[2..3]` [day181.mjs:210](../curriculum/days/day181.mjs#L210)直接說「彼女は私の姉のこと」「僕が借りたのではなく、君が借りたものを代わりに返すんだね」；第165課 `dialogue[2]` [day190.mjs:210](../curriculum/days/day190.mjs#L210)逐一拆解ここ／そこ；第180課第三話輪 [day205.mjs:210](../curriculum/days/day205.mjs#L210)直接指出引用的私是引導員。
- **判斷**：這些句子可成立，亦有示範對話修復的作用，不能把「像教學對話」本身列為日文錯誤。但讀者常可直接抄最後的重述，不必自行整合早先視點。對應「隱含意思」的遷移練習因此較薄；不是已證明學習者無法遷移。
- **方向／驗證**：保留有支架的示範，再於既有練習中安排少量不立即重述、仍能由前文唯一推出的題目；讓學習者說明支持答案的兩條線索，而非只背最後一句。以同文法、不同人物／情境做文字盲判並檢查多解；人耳、速度與情緒的評估另外安排，不能以本輪文字結果代替。

## 附錄C：盤點重算方式

以下唯讀範例在repo根目錄執行；讀取唯一教材入口，不建立檔案。能重算數量、重複表記、答案位置與首次登錄／後用，不會自動判定自然度或缺少先備教學。完整品質判斷依前述逐句閱讀及來源查核。

```js
// node --input-type=module
import { stages } from './curriculum/lessons.mjs';
const lessons = stages.flatMap(s => s.lessons)
  .filter(l => /^general-listening-/.test(l.id));
const words = new Map();
const grammar = new Map();
const answerOrders = new Map();
const rows = lessons.map((l, index) => {
  const n = index + 1;
  let firstWords = 0;
  for (const v of l.vocab) {
    if (!words.has(v.word)) { words.set(v.word, []); firstWords++; }
    words.get(v.word).push(n);
  }
  for (const g of l.grammar) for (const id of g.jlpt ?? []) {
    if (!grammar.has(id)) grammar.set(id, []);
    if (!grammar.get(id).includes(n)) grammar.get(id).push(n);
  }
  const order = l.scene.questions.map(q => q.answer).join(',');
  answerOrders.set(order, (answerOrders.get(order) ?? 0) + 1);
  return { n, id: l.id, title: l.title, goal: l.scene.goal,
    vocab: l.vocab.length, firstWords, grammar: l.grammar.length,
    examples: l.grammar.reduce((sum, g) => sum + g.examples.length, 0),
    dialogue: l.dialogue.length, questions: l.scene.questions.length,
    practice: l.practice.length };
});
console.log(JSON.stringify({ rows, uniqueWords: words.size,
  repeatedWords: [...words].filter(([, ns]) => ns.length > 1),
  grammarFirstAndLater: [...grammar], answerOrders: [...answerOrders] }, null, 2));
```

參考資料限於接續查核：東京外国語大学上列頁面（らしい、ようだ、はず及そうだ接續）、國際交流基金「よう（１）」。JLPT ID有效性只對照既有快取與專案契約；清單不是官方能力保證。工程歷史連結：[PR #144](https://github.com/frobel0520/nihongo-lab/pull/144)、[PR #145](https://github.com/frobel0520/nihongo-lab/pull/145)，不把工程驗證當品質通過。
